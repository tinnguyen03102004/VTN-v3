# Contract: VTN Web Presentation Suite

## 🎯 Goal
Build a professional, web-based presentation deck (`presentation.html`) to showcase the VTN Architects website to senior leadership, verifying both the aesthetic value and technical quality of the project.

## ✅ In-Scope
1.  **Web Presentation (`presentation.html`)**:
    - Integrated Reveal.js presentation.
    - 6-10 slides covering Vision, Design, Tech, and Demo.
    - Fully responsive and styled to match VTN branding.
    - **Language**: All content in **Vietnamese**.
    - **Key Slide**: Project Folder Structure visualization.
2.  **Speaker Notes (`PRESENTATION_SCRIPT.md`)**:
    - Detailed talking points for each slide (in Vietnamese).
    - "Cheat sheet" for the presenter.
3.  **Integration**:
    - Uses existing project assets.
    - Consistent typography (Inter/IBM Plex Mono).

## ❌ Out-of-Scope
- Creating a `.pptx` (PowerPoint) file (We represent the web, we present on the web).
- Video production.
- Hosting configuration (assumes existing local/GitHub Pages hosting).
