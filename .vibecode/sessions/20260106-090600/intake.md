# Intake: VTN Project Presentation Plan

## 🎯 Goal
Create a structured plan and materials for presenting the VTN Architects website to senior management. The presentation should highlight the design aesthetics, technical performance, and user experience innovations.

## 📝 Context
- **Audience**: Senior Management (needs high-level overview + visual impact).
- **Format**: Web-based presentation (recommended for a web project) or Content structure for traditional slides.
- **Key Selling Points**:
    - "Green" & "Bamboo" design philosophy reflected in the digital experience.
    - Performance metrics (SEO/Speed).
    - Multilingual support.
    - Interactive/Parallax elements.
    - **Differentiation**: Direct comparison with the current text-heavy site (vtnarchitects.net) vs. the new visual-first experience.
    - **Language**: The presentation must be entirely in **Vietnamese**.

## ✅ Acceptance Criteria
1.  **Content**: Comprehensive outline in Vietnamese covering Intro, Design, Tech, and Demo.
2.  **Structure Visualization**: A dedicated slide visualizing the project's file structure (Clean Architecture).
3.  **Comparision**: "Old vs New" slide highlighting the shift to Visual Storytelling.
4.  **Format**: A working `presentation.html` using Reveal.js.
